# D4 研究决策、独立训练与重建管线审查

记录日期：2026-10-21。范围从 D4 的模块解耦决策开始，覆盖实际 GPU 实验、ADIS/SDI 阅读和后续计算资源只读评估。详细数值以 [D4 实验报告](../2026-10-20-d4/README.md) 及其中的聚合结果为准。本文不发布实验室接入信息、私有数据或作者提供的代码包。

## 1. 研究决策：重建器不从属于分类

重建是可解释性基础，不以重建指标为最终研究叙事，不意味着允许其质量不足。先独立证明空间与光谱恢复的保真和泛化，再检验下游任务收益。

目标链路为同一 UDC RAW 分别进入成熟 RGB 前端 R 和通用空间—光谱重建器 N1；R 提供 RGB 与候选人脸区域，N1 提供完整空间—光谱矩阵，独立分类器 C 再消费对齐后的结果。概念上的“人脸定位 → 重建结果 → 分类”不应变成由人脸标签或检测框决定 N1 训练数据与视场的串行限制。大 PSF 支持范围下，不能未经验证就裁剪测量。

N1 的主输出为 `[B,21,H,W]`，全局平均谱、重投影和质量状态是辅助输出。训练不使用 Face/Non-face 标签、类别平衡、分类梯度或任务分数。完整 21 通道基线先于低秩压缩；C 独立训练并首先消费冻结 N1。R/N1 共源 RAW 是目标接口，当前标量模拟并未实现已标定的同源 RGB+光谱恢复。

## 2. 已实现与实际执行

对应本地研究提交：

- `dcb5cf7`：一般场景数据、重建接口与分类任务解耦。
- `a7c1a48`：独立来源诊断及在测试查看前固定的一次容量比较。
- `2a00f40`：记录实际 CUDA 训练、泛化诊断与失败边界。

使用完整 CAVE 场景，不按人脸标签选择数据。31 个通过格式检查的场景分为 17 train / 5 validation / 6 development-test / 3 final reserve；另一个场景因格式问题排除。相关场景保守分组。最终 reserve 未用于本轮训练或数值评估，但先前有内容审查，不能称为从未看过的盲测集。所有波段共享增强，增强不增加独立场景数。

实测来源为 `spectral21_20261018_reset01`，采集提交 `18dd598852b1d44ea80b4f6d53e1d2d5656f9e9b`。复用已验证 forward/adjoint；512 核支持经 8×8 积分至 64²，128² 全场景模拟。单位波长权重、单通道观测、空间不变、零边界、像素尺度和 signed tails 仍是近似，不是绝对辐射或 Bayer 标定。

两次 CUDA 训练均实际完成，非计划或 CPU smoke：

| 模型 | 阶段 / 宽度 / 深度 | 参数量 | 已运行 epoch / 选中 epoch |
|---|---|---:|---:|
| 初始模型 | 6 / 64 / 4 | 98,139 | 398 / 338 |
| 预先固定的容量比较 | 8 / 96 / 5 | 285,533 | 304 / 244 |

只按验证目标选择 checkpoint。选中模型在 6 个 development-test 场景的均值：PSNR 24.67 dB、SSIM 0.703、SAM 19.21°、立方体相对 L2 0.419、全局谱相对 L2 0.180、测量相对 L2 0.0341。高频相对误差 0.894，空间梯度误差 0.751。全球平均谱较好不能替代局部光谱与细节验收。

与同场景 Landweber 相比，N1 光谱误差改善，但高频误差和测量残差并未改善。冻结模型输入无波长差异的平均 PSF 后结果接近；这是输入失配测试，不是重新训练的公平无色 PSF 消融，尚不能证明模型利用了波长编码。

16 个 UWA 完整采集的独立来源诊断及一个 Harvard 样本诊断已运行。前者存在辐射域和历史样本暴露限制；后者完整样本读取验证通过，但来源归档只保留前缀，整归档校验未完成。两者不建立广泛跨域泛化结论。Harvard 原幅值下 PSNR 很高而 SAM/相对误差很差，说明固定动态范围的 PSNR 可掩盖暗信号失败。

成熟 YuNet 在 Oracle 三波段代理经合成 Bayer/RGB 的接口测试中实际运行；这不是从真实衍射 RAW 恢复 RGB，也不是人脸检测性能验收。已有默认数值回归为 15 passed，覆盖伴随、导数、CPU/GPU 一致性、共享增强和完整状态等。命令及指标定义见 [复现入口](../../../experiments/d4/README.md)。

**结论：独立通用重建基线已经运行，但高质量通用重建尚未通过验收。** 当前不转入分类训练、低秩压缩或联合优化。没有新增光学采集。

## 3. ADIS 论文与作者快照：分别审查

来源：[ADIS 论文](https://arxiv.org/abs/2608.29230)。实际阅读论文并检查重建公式和图示；作者允许借鉴学习。学习授权不等于公开再分发所有私有文件。

论文的 HQS 数据更新、物理条件输入、多尺度先验、大场景渲染后中心监督值得参考；论文 ODAUF/VST 路线与提供快照中的 HSFAUT 不能当作已确认相同版本。论文滤光响应、28 通道和空间尺度也不能直接视为本项目的 21 波段相机模型。

作者快照实际完成归档 CRC、25 个 Python 文件静态解析和 7 个 NPY 的有限值检查；其中 1 个 Python 文件存在语法错误。没有加载两份权重或执行训练，没有找到明确的包内再分发许可。此发现只适用于该快照，不能归因到论文最终实现。快照及检查细节保留本地，不随报告上传。

快照提供的启发是先生成完整空间—光谱场景，再经过物理编码得到观测；监督和数据管线不依赖分类标签。其约定包含滤光响应、不同归一化、相关/卷积方向、测量尺度和学习频域更新，迁移前必须逐项核对，不能直接替换现有算子。

## 4. SDI 公开仓库：可定位的实现参考

实际克隆并审查 [Krito-ex/SDI](https://github.com/Krito-ex/SDI/tree/2b9db66cf97b0a4c7c636f2525fd606daaa0794d)，固定提交 `2b9db66cf97b0a4c7c636f2525fd606daaa0794d`。README 对应 *Hierarchical Spatial-Frequency Aggregation for Spectral Deconvolution Imaging*，不是 ADIS 同名论文。仓库采用 MIT；若后续复用代码，应保留版权与许可证。本轮未复制其实现进入本仓库。

重建管线：512 全谱场景 → PSF FFT 卷积 → 中心 256 观测 → 空间光谱滤光加权与求和 → HSFAUT 完整 28 通道状态。阶段结合物理残差更新、融合、频域更新及多尺度 U 形 SFAT 先验，HyPaNet 预测正参数。没有分类头；主实现中未发现 ADIS VST 的分数位移模块。

实际完成文件 diff、许可核查和全部 23 个 Python 文件 AST 解析，均通过；未安装依赖、执行训练或复现论文指标。公开仓库没有配套硬件 NPY、权重、训练数据和完整环境清单，不能凭语法通过认定可直接运行。

主要适配风险：

- 与私有快照相比，FFT 从相关改为卷积，频域式修正为共轭与模平方；非对称实测 PSF 必须验证方向和偶数核原点。
- 频谱经过学习降采样，形式类似闭式解不等于真实 forward 的精确逆。
- renderer 使用 `no_grad`，不能直接用于需要反向传播的数据一致性损失。
- renderer 与内部更新的 padding、15/28 与 15 缩放、未限定轴的 fftshift 需要解释和测试。
- 28/256/512、设备选择及默认 method/template 存在硬编码或不一致。
- 作者流程用 test 目录逐轮择优；迁移时应明确为 validation，另留独立 test。其场景归一化、量化及 PSNR 定义与 D4 不同，分数不可直接横比。

建议学习多尺度先验、物理条件输入和上下文保留，继续保留本项目经过测试的 A/At。作者滤光响应只能作为明确标注的假设，不能冒充本相机实测响应。作者默认训练预算显著大于 D4 有限试验，但配置预算不是本轮已验证的训练结果，增加 epoch 也不保证可辨识性。

## 6. 下一步与停止边界

1. 冻结下一轮数据、尺度、噪声、预算和验证协议；扩大合法独立场景，不用增强替代场景数量。
2. 检查 PSF 积分前后波长差异、边界/halo 和空间可恢复性，先解释物理限制。
3. 在相同已验证 A/At 下比较多尺度先验，独立测试全部 21 通道、梯度与幅值约定。
4. 根据训练/验证证据改善局部光谱与高频恢复；已有 development-test 不再作为调参目标，保留 final reserve。
5. 待 N1 独立质量验收后，再进行冻结 N1 的分类和同源 RGB/光谱比较。
