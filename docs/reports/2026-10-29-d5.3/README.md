## 主要结论（详见 `scientific_conclusions.md`）

1. **空间结构收益可重复，但比单 seed 印象小**：SSIM +0.0053、空间梯度 −0.052、测量残差
   −0.0055 通过预注册判据（3/3 seed、9/9/9 与 9/9/8 场景）；PSNR +0.317 dB 与 HF −0.0498
   方向一致但未达判据（单 seed 只有 6/9、7/9 场景）；**SAM 方向相反**（+0.132°，消色差更好）。
2. **"网络利用了色散的光谱信息"不成立**：零和光谱扰动在**逐像素**上基本不可见（配置均值
   0.004–1.43，全部 <2σ；最强配置也只有约 7% 像素超 2σ），但在**已知模板**的整幅匹配滤波意义上
   可以很强（最高 731，相邻 10 nm 只有 1.9–45）；冻结 A6 只恢复 1.87%，方向相关性 0.005，
   比它对纯噪声的响应低 5 倍。消色差网络响应恰好为 0（恒等），验证算子盲性在网络路径上也成立。
3. **400 epoch 仍未让消色差臂收敛**：2/3 个消色差 run 跑满 400 且 best 在最后 60 epoch
   （358、366），而 3/3 个色散 run 都被 patience 停止（271/283/264）。所有差值只能按
   "统一 400 epoch 预算"解读，不能读作收敛能力之差。
4. **逐波段能量误差是独立维度、与 SAM 相反，但只有少数波段稳定**：21/21 波段更低、3/3 seed
   同向、19/21 超过跨 seed sd，可是只有 6/21 波段（470/480/490/520/530/590）同时满足
   "每 seed ≥8/9 场景"，450/460 与 600–650 不可声称。详见 `per_band_analysis.md`。
5. **S3 换核对照：空间优势不依赖"算术平均核"这一个参考选择**。换成 550 nm 真实波段核后，
   色散臂通过判据的指标从 3/8 变成 6/8（PSNR +0.444 dB、cube −0.0122、HF −0.0621 转稳），
   方向不翻转。但增量来自参考臂更弱（550 臂比平均核臂差 0.127 dB），所以 **S1 的 +0.32 dB
   才是保守值**，不能说"色散好 0.44 dB"；也不能说所有模糊频响差异已被排除（两个参考核都不
   匹配色散算子的频响）。

## 明确不支持的结论

- 不支持"色散 PSF 提高了光谱角精度"：SAM 三个 seed 全部变差。
- 不支持"逐波段能量误差在每个 seed、每个场景上都更好"：只有 6/21 波段通过全部三条判据。
- 不支持"色散比消色差好 0.44 dB"：S3 的增量全部来自 550 nm 参考臂更弱；S1 的 +0.32 dB 才是保守值。
- 不支持"550 nm 与平均核在训练上完全等价"：PSNR/SSIM/cube 上有小而方向一致的差别。
- 不支持"空间收益来自网络利用了色散带来的光谱信息"：反事实响应比噪声响应小 5 倍。
- 不支持"零和光谱差异一律低于噪声"：逐像素基本不可读，但已知模板的匹配滤波 SNR 最高 731。
- 不支持"消色差臂已到其收敛上限"：2/3 run 在预算边界仍在改善。
- 不支持任何冻结测试集或真实 RAW/硬件层面的结论：PSF 仍是 signed shape-only 数值模型。
- 不支持"多 seed 结论已足够强"：n = 3，只能支持方向与量级的判断，不能给出置信区间。

## 下一步（按优先级）

> S3（Achromatic-550 训练对照）已于 2026-10-30 完成，见上方"执行记录"、§5 与
> `s3_control_analysis.md`；它**不再**是待执行项。

1. **统一延长预算**：若要把"收敛能力"作为结论，必须对全部 6 个臂统一延长（例如 600 epoch），
   而不是只给消色差臂加。
2. **更强的反事实**：把扰动限制在训练分布内（幅度小、波段组合来自场景统计），验证"小幅度
   零和扰动是否可恢复"；本轮 0.5 强度、‖ΔX‖≈42，属于明显的分布外输入。
3. **降低噪声或固定绝对噪声**：本轮逐像素 SNR 的配置均值最高 1.43（强度 1.0、远间隔），
   如果把噪声降到 0.1% 前向 RMS，配置均值会整体抬高一个数量级；这直接检验"信息不足"
   还是"反演器不足"，也能把 B2 的"已知模板可检测"与"盲恢复失败"区分得更干净。
4. **频响控制核**：构造与色散算子逐频匹配的波束无关核，才可能真正排除"模糊频响差异"；
   现有的平均核与 550 nm 核只覆盖了两种取值。
5. S4（A-large / C6）只在 1–4 有结论后进行。
