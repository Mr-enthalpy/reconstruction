# D5.2 S1/S3：实测色散 PSF 与消色差 PSF 的匹配对照（kunqian 双卡）

日期：2026-10-28
运行标识：`s1_chromatic_20261028` / `s3_achromatic_20261028`
代码：`8c50c88`（含 PSF 来源校验与 best-epoch 指标记录）
设备：2 × NVIDIA GeForce RTX 3090（24 GiB），同一租约并行

## 1. 目的

D5.2 的 S1（Chromatic，实测色散 PSF）与 S3（Achromatic，21 个波段共用平均核）是
同一数据、同一配置、同一 seed 下**只换 PSF** 的匹配对照。本报告回答两个问题：

1. 在完整预算下，两臂的训练结果分别是什么？
2. 在**同一验证集**上，实测色散 PSF 相对消色差核是否有可测量的重建贡献？

不涉及冻结测试集、不涉及硬件采集、不做分类或 RGB 前端。

## 2. 设计

| 项 | 值 |
|---|---|
| 数据 | `train.npz` 39 场景 / `val.npz` 9 场景，21 波段 450–650 nm，512×512 |
| 配置 | `experiments/d5_2/configs/a6_formal.json`，A6 CNN-PGD（98,139 参数），6 stages，batch 1，100 step/epoch，300 epoch 上限，`patience=40`，`eval_every=5` |
| seed | 20261021（两臂相同） |
| 唯一差异 | `--kernel-file`：`kernels.npz`（S1） vs `kernels_achromatic.npz`（S3） |
| 消色差核 | 21 个色散核取均值后复制 21 份，每波段和为 1（`mean(0)` + repeat，已核对） |
| 选模 | 最小验证重建目标（训练前确定，两臂同一条规则） |

**预注册判定规则**（在启动前写下，避免事后挑选）：

- 主对比：各臂按规则选出的 best，在同一 9 个验证场景上逐场景配对；
- 次对比：同一 epoch 的轨迹，用于排除"预算不对称"造成的假象；
- 判定"有贡献"需同时满足：(a) 配对差方向在 ≥7/9 场景一致；(b) 平均差幅度超过该指标
  在平台期的 epoch 间波动（末 40 个指标 epoch 的 std）。

## 6. 结论

1. **实测色散 PSF 对空间重建有可测量的贡献**：在同一验证集、同一选模规则下，
   色散臂的 PSNR 高 0.42 dB、高频相对误差低 0.063、空间梯度误差低 0.065，且高频在
   **9/9** 场景一致；幅度超过平台期 epoch 间波动。
2. **这种贡献不是"光谱更准"**：SAM 反而略偏向消色差（9.73° vs 9.90°），全局光谱误差
   两者相当。可以理解为色散核提供的是**波段相关的编码多样性**，主要改善空间/高频与
   测量一致性，而光谱角误差主要由数据与网络先验决定。
3. **贡献需要足够的训练预算才显现**：≤40 epoch 时两臂无差别，约 100 epoch 后色散臂
   才稳定领先。这与 24,800 步基线报告"充分训练缓解高频不足"的结论一致。
4. **Achromatic 臂在本配置下没有早停**（跑满 300 epoch，best 在 296），而色散臂在 248
   就触发 `patience=40`。按预注册规则，这不构成问题：主对比用各自规则选出的 best，
   次对比用公共 epoch；两者给出的差距一致。

## 7. 明确不支持

- **不是** 冻结测试集结果：全程只用 train/val，`test.npz` 未上传、未加载。
- **不是** 多 seed 结论：两臂各 1 个 seed；平台期波动只是 epoch 间变异的代理，不等于
  种子方差。
- **不是** 绝对物理验证：PSF 仍是 signed shape-only 近似，未经辐射度/Bayer/视场标定；
  消色差对照只回答"波段相关核 vs 平均核"，不回答真实光学链路是否被正确标定。
- **不是** "色散 PSF 在所有任务上都更好"：SAM 未改善；分类/检测等下游任务未评估。
- **不是** 大模型结论：只测了 A6（98k 参数）。
