# Legacy Notes

This repository may eventually include legacy comparisons and dense debug pathways, but they are not the main route.

Dense PSF materialization is allowed only for:

```text
- small debug cases
- parity tests
- legacy comparisons
- baseline sanity checks
```

Legacy three-band reconstruction may exist only as a smoke test or benchmark. Active architecture and method names should support arbitrary spectral band count `L`.

No legacy compatibility layer is implemented during initialization.
